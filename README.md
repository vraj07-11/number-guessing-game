# 🔢 Number Guessing Game

An interactive and engaging number guessing game built with **JavaScript**. Test your intuition and logic as you try to guess the secret number within a limited number of attempts!

## ✨ Features

- **Interactive Gameplay:** Dynamic feedback (too high, too low, or correct) for every guess.
- **Score & Attempt Tracker:** Keeps track of your remaining attempts and past guesses.
- **Restart Functionality:** Easily reset the game to play another round.

## 🛠️ Tech Stack

- **Frontend:** JavaScript (ES6+), HTML5, CSS3
- **Version Control:** Git & GitHub
